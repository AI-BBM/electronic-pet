# 电子宠物 · 产品层 PRD

- 产品名：电子宠物（electronic-pet）
- 形态：PC 端网页
- 目标用户：学校班级的学生（教师可扩展管理）
- 部署：https://pet.aibbm.cn （宝塔服务器 112.124.59.165）；宠物图片素材上 OSS

## 愿景
把班级日常激励变成看得见的成长：每个学生领养一颗蛋，孵化出自己的电子宠物，用日常表现挣积分喂养，宠物随积分升级进化，陪伴与见证学生的进步。

## 目标（MVP）
1. 一个班级的学生可以领取（认领）自己的宠物蛋，并孵化出宠物；
2. 学生可以给自己的宠物加分；
3. 加分累积推动宠物升级，外观随之进化；
4. 宠物种类尽可能多（首批 12 种，后续可扩）；
5. 宠物素材透明背景 PNG，适配任意页面背景。

## 非目标（MVP 不做）
- 多班级/多学校管理后台、权限体系（仅预留扩展）；
- 移动端适配；
- 社交功能（互访、赠送）。

## 关键体验原则
- 学生身份轻量化进入：班级码 + 姓名/学号，不设复杂注册；
- 孵化要有仪式感（破壳动画）；升级要有即时反馈（进化动画/光效）；
- 页面即看即玩：打开页面能看到自己的宠物、等级、下一级目标。

## 里程碑
| 里程碑 | 范围 |
|---|---|
| M1 领蛋与孵化 | 班级进入、领蛋、破壳孵化、宠物档案 |
| M2 加分与升级 | 加分入口、积分流水、等级阈值与进化 |
| M3 图鉴与展示 | 宠物图鉴（已收集/未解锁）、班级墙展示 |
