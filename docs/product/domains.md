# 电子宠物 · 域层

## 域划分

### 1. 班级域（Class）
- 概念：班级（classCode 班级码）、学生（student：姓名/学号）
- 职责：班级进入（班级码）、学生身份建立与识别
- 规则：同一学生（同班同学号）只能认领一只宠物；重进页面凭班级码+学号找回宠物

### 2. 领养域（Adopt）
- 概念：宠物蛋（egg）、孵化（hatch）、宠物档案（pet profile）
- 职责：发蛋、选蛋/随机蛋、破壳孵化、确定宠物种类
- 规则：
  - 蛋分颜色（视觉差异，孵化前不告知种类，制造惊喜）；
  - 孵化结果由服务端按种类权重随机确定（稀有度：普通/稀有/史诗）；
  - 一经孵化，宠物与学生绑定，不可更换。

### 3. 成长域（Growth）
- 概念：积分（points）、积分流水（point log）、等级（level）、进化（evolution stage）
- 职责：加分入账、流水记录、等级计算、进化触发
- 规则（MVP 阈值，服务端可配置）：
  - Lv1 幼年期：孵化即得；
  - Lv2 成长期：累计 20 分；
  - Lv3 完全体：累计 60 分；
  - 单次加分 1–10 分；加分需填写理由（如“作业优秀”），流水留痕；
  - 升级即时生效，页面播放进化表现。

### 4. 素材域（Assets）
- 概念：宠物形象素材（透明 PNG）、素材索引（species manifest）
- 职责：素材上 OSS、按种类/阶段索引给前端
- 规范见 [assets-spec.md](assets-spec.md)

## 域间关系
班级域建立学生身份 → 领养域用学生身份绑定宠物 → 成长域读写宠物积分与等级 → 素材域为前端提供各级外观。
