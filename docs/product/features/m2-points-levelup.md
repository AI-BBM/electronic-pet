# 特性 PRD · M2 加分与升级

## 用户流程
1. 在「我的宠物」页点击「加分」；
2. 选择/填写理由（预设标签：作业优秀、课堂表现、劳动卫生、进步之星…；或自定义文本）；
3. 选择分值（1–10，默认 1）；
4. 提交 → 积分入账，进度条动画；跨过阈值立即播放进化动画，宠物外观切换到下一阶段。

## 功能规则
- 加分即流水：时间、分值、理由，不可改删（MVP 无撤回）；
- 等级阈值（服务端可配置）：
  - Lv1 幼年期：孵化即得（0 分）
  - Lv2 成长期：累计 20 分
  - Lv3 完全体：累计 60 分
- 满级后继续积分，展示总积分排行（M3）；
- MVP 加分为学生自助；预留教师批量加分口令（后续里程碑）。

## 进化表现
- 升级瞬间：光效 + 破立绘切换（新阶段透明 PNG）；
- 档案页展示当前阶段与下一阶段剪影（未达成的下一阶段用黑色剪影呈现悬念）。

## API 草案
- POST /api/points {reason, value} → {pet, levelUp: bool, level}
- GET /api/pet/me/log?page= → 积分流水分页

## 验收标准
- 加分后档案与流水立即一致；
- 19 分加 1 分触发 Lv2，外观与进度条同步更新，重复提交不重复计分；
- 流水分页正确。
