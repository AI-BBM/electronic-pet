# 特性 PRD · M1 领蛋与孵化

## 用户流程
1. 打开 https://pet.aibbm.cn，输入班级码 + 姓名 + 学号进入班级（无密码，学号即身份键）；
2. 进入「领蛋」页：展示蛋架（若干颗不同颜色的蛋），学生选一颗（或随机）；
3. 点击蛋破壳孵化（前端动画，约 2–3 秒），揭晓宠物种类；
4. 进入「我的宠物」页：展示宠物形象（Lv1 幼年期）、名字、等级、积分、下一级目标。

## 功能规则
- 同一学号只能认领一次；重复进入直接回到「我的宠物」；
- 蛋颜色仅视觉差异；孵化种类由服务端随机：
  - 普通 70%（8 种）、稀有 25%（3 种）、史诗 5%（1 种），种类池见 species manifest；
- 宠物名：学生可自定义一次（默认用种类名）；
- 服务端持久化：班级、学生、宠物、种类、等级、积分。

## 页面清单（PC 端，1280px+ 优先）
| 页面 | 要素 |
|---|---|
| 进入页 | 班级码、姓名、学号表单 |
| 领蛋页 | 蛋架（可选蛋/随机）、领取按钮 |
| 孵化过场 | 破壳动画 + 种类揭晓 |
| 我的宠物 | 宠物立绘（透明 PNG）、名称、Lv/积分进度条、加分入口 |

## API 草案
- POST /api/join {classCode, name, studentNo} → {token, pet?}
- GET /api/eggs → 蛋列表
- POST /api/adopt {eggId} → {pet}（随机定种类，事务内绑定学生）
- GET /api/pet/me → 宠物档案 + 积分流水摘要

## 验收标准
- 50 个学生并发领蛋，无重复种类绑定错误；
- 同学号二次进入不产生第二只宠物；
- 孵化动画流畅，揭晓种类与档案一致。
