# 特性 PRD · M5 移动端适配

## 背景
当前页面 viewport 固定 width=1280（桌面布局），手机打开需缩放横向滚动。黄总 13:32 要求适配手机端。

## 适配范围（全视图）
进入页 / 领蛋页 / 孵化过场 / 我的宠物 / 宠物图鉴 / 班级墙 / 教师登录 / 教师工作台。
优先级：我的宠物与加分 > 领蛋孵化 > 教师工作台（课堂随手用）> 图鉴/班级墙 > 进入页。

## 技术口径
1. viewport 改 `width=device-width, initial-scale=1`；
2. 响应式断点：≥1024px 保持现有桌面布局；<1024px 单列自适应（max-width + 流式布局），不做独立移动站；
3. 触屏友好：可点目标 ≥44px、表单字号 ≥16px（防 iOS 聚焦缩放）、去掉 hover 依赖；
4. 素材已就绪（512px 透明 PNG，最大边展示约 40-60vw，无需出新图）；
5. 功能零增删：纯展示层与交互适配，API 不动。

## 验收标准
- 375px（iPhone SE/mini）与 414px 宽度下全视图无横向滚动、无文字截断、按钮可点；
- 桌面 1280px 布局不回退、不变形；
- 教师工作台表格在窄屏降级为卡片式列表；
- 主流浏览器（Chrome/Safari/微信内置）实测可用。
