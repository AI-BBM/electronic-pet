# 特性 PRD · M3 图鉴与班级墙

## 宠物图鉴
- 展示全部种类（12 种首批）：已孵化的展示彩色立绘 + 拥有者数量；未解锁展示黑色剪影 + 「??？」；
- 每种类展示三阶段缩略图与稀有度。

## 班级墙
- 按积分排行的班级展示墙：头像位为各学生的当前阶段宠物立绘；
- 支持按积分/最近升级排序；
- 点击任一宠物可查看公开档案（种类、阶段、积分、最近理由）。

## API 草案
- GET /api/dex → 种类列表 + 解锁状态
- GET /api/class/wall?sort=points|recent → 班级宠物墙

## 验收标准
- 未解锁种类不泄露立绘 URL（剪影由素材预生成）；
- 排行实时反映加分。
